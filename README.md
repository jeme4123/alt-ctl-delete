## Local Development

Clone the repository:

```bash
git clone https://github.com/jeme4123/alt-ctl-delete.git
```

Navigate into the project:

```bash
cd alt-ctl-delete
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
